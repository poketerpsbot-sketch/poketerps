# Sources des médias de démonstration

Les 20 images ci-dessous sont des **photos d’illustration**. Elles ne représentent ni un produit réel correspondant aux fiches fictives, ni une marque, ni une offre. Le script `scripts/sync-demo-media.ts` vérifie à chaque exécution l’existence du fichier, sa page Commons, son MIME et le nom court de sa licence avant tout upload.

Après validation, le script télécharge la vignette fournie par Wikimedia Commons, applique l’autorotation, limite l’image à 1 600 px et crée un dérivé WebP (qualité 82). Il enregistre la source, le crédit, la licence et le lien de licence dans les métadonnées Supabase Storage **et** dans `entry_images`. La page détail affiche ces informations ainsi que la mention de transformation.

## Obligations de réutilisation

- Les licences CC BY et CC BY-SA imposent de conserver le crédit, le lien vers la licence, la source et l’indication de modification. Le `figcaption` de la page détail les rend visibles.
- Les dérivés de fichiers CC BY-SA doivent rester sous la même licence ou une licence compatible. Le manifeste conserve donc la licence propre à chaque fichier; elle n’est pas remplacée par la licence du code du projet.
- Les fichiers CC0 ou marqués domaine public n’exigent généralement pas d’attribution, mais leur provenance reste affichée par transparence.
- Ne pas détacher un objet Storage de son enregistrement `entry_images` ou supprimer ses champs d’attribution. Relancer le script est la méthode prévue pour restaurer l’association de façon idempotente.
